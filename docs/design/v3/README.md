# Valan design v3

Exported on 2026-11-20 from the canvas "Valan — Design da app (v2)" (https://claude.ai/artifact/GVJqTHVHNeajzLFHBfArNs), after it was adapted to the zigzag-wave logo and the orange palette.

- `design-spec.md`: the source of truth (tokens, components, every screen's content, states and acceptance criteria). When a picture and the spec disagree, the spec wins.
- `NN-*.png`: one screen each, 390 × 844 at 2x, for visual comparison. `00-visao-geral.png` shows all of them.
- `valan-mockups-v3.html`: every screen as plain HTML with the exact CSS values; open it in a browser or read a screen's section for sizes and colours.

This supersedes `docs/design/mockups/` (design v2 of 17 November), which the app was built from. Where this design conflicts with a decision recorded in CLAUDE.md (for example step 1 of the new-listing flow, or the condition scales), CLAUDE.md wins until the founder decides otherwise.
